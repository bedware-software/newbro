# Vimperium — варианты логотипа

Исследование знака для ребрендинга Newbro → **Vimperium**. Все знаки строятся вокруг V, в стилистике cyberpunk,
с глитч‑анимацией и обязательной малой версией для левого верхнего угла тулбара (≈20px) и фавиконки (16px).

## Выбран: Crossed Katana Badge

Знак `svg/blade-01-crossed-katana.svg` стоит в приложении:

- **Иконка приложения.** `resources/icon.png` (1024px) и `resources/icon.ico` нарисованы из полного знака с цветами COMMAND
  на глубоком тёмном фоне `oklch(0.14 0 0)`. В .ico слоты 16–48px взяты из `svg/blade-01-crossed-katana.icon-small.svg`
  (малая версия на той же фасочной табличке), слоты 64–256px из полного знака.
- **Кнопка Menu — орб в начале тулбара.** Полный знак во всю высоту тулбара (47px), как орб «Пуск» в Vista
  (`BrandMark variant="full"` в `src/renderer/src/components/BrandMark.tsx`): на своей тёмной табличке при любой теме,
  в тройке цветов режима Vim. При смене режима и при наведении он глитчит, при Reduce motion стоит на месте.
  Меню выпадает из него.
- **Settings → About.** Тот же живой полный знак, 48px, в цветах COMMAND; глитчит при наведении.
- Малая версия (`BrandMark variant="small"`) осталась в компоненте для мелких размеров.

## Что здесь

- `index.html` — галерея: все варианты, переключатели темы (тёмная / глубокая / светлая), режима Vim
  (COMMAND ↔ INSERT: знак перекрашивается в тройку цветов режима, как комета на адресной строке), четыре вида глитча,
  свечение, просмотр крупно (иконка приложения, словесный знак, мок угла тулбара), копирование SVG с запечёнными цветами.
  Открывается локально как файл, внешних зависимостей нет (кроме шрифта JetBrains Mono для подписей).
- `svg/<id>.svg` — полный знак, `svg/<id>.small.svg` — малая версия того же знака (1–3 фигуры), `svg/<id>.wordmark.svg` — словесный знак, если есть.
- `svg-round1-minimal/` — первый, минималистичный раунд (до правки «слишком примитивно»), для сравнения.
- `proofs/<id>.png` — проверочный лист каждого знака (уменьшен до 75%): 128px в обеих тройках, малая версия 32/24/16px и пиксельный зум,
  знак в моке тулбара и вкладки на тёмной и светлой теме.
- `data.json` — метаданные: описания, идеи глитча, оценки рецензентов, ранжирование жюри.
- `BRIEF.md` — бриф и контракт на SVG.

## Контракт на SVG

Цвета только через переменные, поэтому любой файл можно положить в приложение как есть и перекрашивать по режиму и теме:

| переменная | смысл | COMMAND (тёмная тема) | INSERT (тёмная тема) |
|---|---|---|---|
| `--c1` | основной | `oklch(0.74 0.14 240)` синий | `oklch(0.80 0.18 142)` зелёный |
| `--c2` | второй | `oklch(0.66 0.19 292)` фиолетовый | `oklch(0.89 0.16 110)` лайм |
| `--c3` | третий | `oklch(0.83 0.12 205)` циан | `oklch(0.77 0.13 182)` бирюза |
| `--hot` | горячий акцент | `oklch(0.72 0.22 350)` маджента | `oklch(0.78 0.18 60)` янтарь |
| `--bg` / `--fg` | фон и текст UI | как в теме | как в теме |

`viewBox="0 0 64 64"`, без `width`/`height`, без `<text>` (буквы — пути). Малая версия без фильтров и градиентов.

## Как использовать в приложении

Знак в углу: `<svg><use href="#…"/></svg>` из малой версии внутри кнопки сайдбара, цвета наследуются от `--vim-edge-command-*` /
`--vim-edge-insert-*` (это те же тройки). Глитч при смене режима — три копии знака, `clip-path` срезами по `steps()`,
как в галерее (`index.html`, блок «glitch engine» в стилях).
